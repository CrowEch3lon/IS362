# IS 362 Final Project

## Setup
1. Clone the repo
2. Create a `.env` file at the repo root with `CENSUS_API_KEY=your_key_here`
3. Install dependencies: `pip install requests numpy pandas geopandas shapely python-dotenv folium`
4. Run `DanielFoulen_IS362_FinalProject_Pt1.ipynb` top to bottom
5. Run `DanielFoulen_IS362_FinalProject_Pt2.ipynb` top to bottom

First run of Part 1 takes approximately 6 to 7 minutes due to the MTA data pull.
All subsequent runs load from cache.
